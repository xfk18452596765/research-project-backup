# RL-PRMAC论文项目

## 研究题目

面向海面船舶多跳无线通信的强化学习增强路径预约MAC协议研究

## 管理规则

1. 每天新产生的文件先放入daily目录对应的Day目录；
2. 当天Markdown文档放入docs；
3. 当天Python代码放入code；
4. 稳定版仿真代码整理到scripts/simulation；
5. 原始实验数据放到results/raw；
6. 处理后的实验数据放到results/processed；
7. 论文正式图片放到figures；
8. 论文正文和汇报材料放到paper；
9. 核心文献放到reference/core；
10. ns-3扩展内容单独放到ns3。

## 技术路线

DCF → Fixed-PRMAC → RL-PRMAC
