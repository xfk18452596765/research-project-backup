# Failure-cost attribution plan

The required decomposition is: source and relay queue wait; reservation contention; PR_REQ/ACK/NACK; retry/BEB; protected DATA/H_ACK; inter-segment wait; RELEASE/cleanup; and reservation-blocked versus DCF-contention time. Control accounting includes count, bytes, airtime, reservation attempts/grants/failures, effective hops, and delivered payload. Spatial-reuse and hidden-terminal traces are classified before any candidate gate is evaluated.

The historical baseline reported a mixed root cause. Per the preregistered policy, this stage must return `REDESIGN_HOLD` if the top two attribution categories do not explain at least 70% of excess delay or throughput loss; it must not implement candidates speculatively in that case.
