# Candidate preregistration

The authoritative, frozen machine-readable registry is `configs/candidate_registry.json`. C1 narrows local grant blocking, C2 piggybacks a final release on H_ACK with explicit-release/lease fallback, and C3 bounds same-flow same-segment FIFO grant reuse to two packets. No fourth candidate, dynamic K/CW, central scheduling, or seed selection is permitted.
