# Day07：DCF指标采集任务计划

## 一、任务定位

Day07严格沿用原目录：

```text
daily/Day07_DCF指标采集/
```

不改名，不新建另一套Day07目录。

Day06已经完成单跳碰撞、ACK超时、BEB和重传，但明确尚未实现多跳逐跳转发。Day07在不修改Day03—Day06稳定代码的前提下，新增固定路由多跳DCF和指标采集扩展。

## 二、今日目标

完成以下流程：

```text
源节点入队
→ 独立DIFS与随机退避
→ 单跳DATA/ACK成功
→ 数据包推进到下一中继
→ 中继重新入队
→ 重新执行DIFS、退避和竞争
→ 逐跳重复
→ 最终目的节点送达
```

同时采集：

- 端到端时延；
- 每跳时延；
- 排队时延；
- 接入时延；
- 成功发送至ACK时延；
- 每包竞争次数；
- DIFS启动次数；
- 选中的退避槽数；
- 实际消耗的退避槽数；
- 累计退避时间；
- 退避冻结与恢复；
- 碰撞事件和碰撞包尝试；
- ACK超时；
- 重传；
- 成功跳数和丢弃跳数。

## 四、完成标准

1. 固定路由数据包能够逐跳到达目的节点；
2. 中继节点必须重新入队并重新执行DCF；
3. 2、4、6跳端到端时延随跳数增加；
4. 无竞争、每跳退避10槽时，端到端时延等于单跳理论时延乘以跳数；
5. 成功跳数、竞争次数、DIFS次数与跳数一致；
6. 累计退避槽数等于每跳实际倒计时槽数之和；
7. Day06碰撞、ACK超时、BEB和重传能力仍可使用；
8. Day03—Day07回归测试全部通过。
