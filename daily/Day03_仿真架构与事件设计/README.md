# Day03：仿真架构与事件设计

## 今日目标

完成Python离散事件仿真的核心对象、事件类型、状态和数据流设计，并搭建一个可运行的最小事件引擎。今天暂不实现完整DCF。

## 今日任务

1. 明确Event、Simulator、Packet、Node、Channel和MetricsCollector的职责；
2. 统一事件时间、优先级和稳定排序规则；
3. 定义节点、数据包和信道状态；
4. 为DCF、Fixed-PRMAC、RL-PRMAC预留统一接口；
5. 完成最小可运行事件引擎；
6. 通过冒烟测试验证事件顺序、队列、信道和指标采集。
