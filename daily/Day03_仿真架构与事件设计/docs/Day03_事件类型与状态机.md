# Day03_事件类型与状态机

## 基础事件

`PACKET_ARRIVAL`、`BACKOFF_START`、`BACKOFF_EXPIRE`、`TX_START`、`TX_END`、`RX_SUCCESS`、`RX_FAILURE`、`ACK_TIMEOUT`、`RETRY`、`DROP`、`PR_REQUEST`、`PR_CONFIRM`、`PR_FAIL`、`RESERVATION_RELEASE`、`RL_DECISION`、`METRIC_SAMPLE`。

## MAC状态

```text
IDLE
BACKING_OFF
WAIT_CTS
TRANSMITTING
WAIT_ACK
RECEIVING
RESERVING
WAIT_RESERVATION_ACK
```

Day04先使用`IDLE`、`BACKING_OFF`、`TRANSMITTING`、`WAIT_ACK`和`RECEIVING`。

## 数据包状态

```text
CREATED → QUEUED → CONTENDING → TRANSMITTING
         → FORWARDED → DELIVERED
         → DROPPED
```

## 典型DCF事件链

```text
PACKET_ARRIVAL
→ 入队
→ BACKOFF_START
→ BACKOFF_EXPIRE
→ TX_START
→ TX_END
→ RX_SUCCESS
→ ACK
→ 下一跳或DELIVERED
```
