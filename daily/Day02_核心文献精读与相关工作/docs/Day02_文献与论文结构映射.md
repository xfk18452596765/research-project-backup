# Day02_文献与论文结构映射

## 第一章：绪论

使用EASO-TDMA说明海面船舶网络存在多跳中继、中继负载不均和时延敏感业务需求。

使用EMAC说明传统DCF面向单跳设计，多跳时同一业务流上下游节点发生流内竞争。

## 第二章：相关理论与研究现状

- 以EMAC说明多跳协同预约；
- 以Kanodia说明priority tag、分布式优先级和多跳时延补偿；
- 以EASO-TDMA说明固定资源分配与中继负载失配；
- 后续补充Neuro-DCF和QL-CSMA/CA说明学习型MAC。

## 第三章：系统模型与问题定义

- EMAC支撑流内竞争；
- Kanodia支撑端到端目标需要跨跳协调；
- EASO-TDMA支撑船舶汇聚业务和中继瓶颈模型。

## 第四章：RL-PRMAC协议设计

- EMAC支撑路径预约框架；
- Kanodia支撑业务优先级、竞争窗口动作和时延补偿；
- EASO-TDMA支撑队列、忙碌率和中继负载进入决策依据。

## 第五章：实验设计

- EMAC借鉴链式与交叉竞争拓扑；
- EASO-TDMA借鉴船舶到岸站的多跳汇聚场景；
- Kanodia支撑告警业务、不同优先级和高负载实验。
