# 03 真实多跳拓扑标定

链路使用 `ConstantSpeedPropagationDelayModel` 与
`LogDistancePropagationLossModel`。最终冻结值：

- spacing = 20 m
- exponent = 4.0
- reference distance/loss = 1 m / 46.6777 dB
- TxPower = 22 dBm
- RxSensitivity = -85 dBm
- CcaEdThreshold = -93 dBm
- RxNoiseFigure = 7 dB

理论相邻 RSS 约 -76.72 dBm，两跳 RSS 约 -88.76 dBm。因此相邻稳定解码，
两跳不能直接解码但可以载波感知。正式矩阵前逐对发送 probe；实测解码矩阵、
基于同一传播参数的 CCA 矩阵和逐对 CSV 分别保存在
`results/topology/connectivity_matrix.json`、
`carrier_sense_matrix.json`、`topology_calibration.csv`。

隐藏终端采用 A=(0,0,0)、B=(30,0,0)、C=(60,0,0)。A/C 到 B 的理论 RSS
约 -83.76 dBm；A 到 C 约 -95.79 dBm，低于 CCA 阈值。
