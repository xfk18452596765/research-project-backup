# 02 ns-3 架构设计

## 数据路径

每个节点安装一个 `AdhocWifiMac` 802.11b `WifiNetDevice` 和
`PacketSocketFactory`。每个相邻方向有独立的已绑定 PacketSocket，目标是
下一跳 MAC 地址，不安装 IP 路由。程序对非相邻语义发送执行硬断言。

DCF 只有在接收 socket 解析 `flow_id/packet_id/route_index` 后，才将包加入
该中继的本地 FIFO 并调度下一跳。

## Fixed-PRMAC 下层 spike

选定修改点是 `Txop::StartAccessAfterEvent`：

- 普通控制帧保持原生 DCF；
- PR_ACK 安装有期限的本地 reserved grant；
- reserved MPDU 把随机 backoff 置零，但仍调用 `ChannelAccessManager`；
- 解码到 PR_REQ 的本地冲突节点安装 `blockedUntil`；
- blocked 节点到期后重新请求接入；
- grant 的开关和本地 block 均有 trace source。

该设计没有修改 PHY，也没有强制接收成功。干扰、前导检测、重传和接收结果
仍由 ns-3 Wi-Fi 决定。状态是每个 Txop/节点独立持有，不存在全局介质锁。
