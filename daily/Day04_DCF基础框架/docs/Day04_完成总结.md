3. 完成随机退避过程；

## 三、完整事件链

PACKET_ARRIVAL
→ DIFS_START
→ DIFS_END
→ BACKOFF_START
→ BACKOFF_EXPIRE
→ TX_START
→ TX_END
→ ACK
→ DELIVERED
